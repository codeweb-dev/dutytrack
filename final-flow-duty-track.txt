DUTYTRACK: ROLE-BASED ROADMAP (UPDATED)

DutyTrack: A Web-Based OJT Attendance and Duty Hours Monitoring System


==================================================
SYSTEM OVERVIEW
==================================================

DutyTrack is a web-based system designed to monitor OJT attendance, duty hours, and student productivity using a role-based structure.

The system supports five main roles:

1. Admin
2. OJT Coordinator
3. Professor
4. Company Supervisor
5. Student


==================================================
TECH STACK
==================================================

Frontend and Backend Framework:
- Laravel 12

Reactive Components:
- Livewire 4

Database:
- MySQL

UI Component Library:
- Flux Components

Role and Permission Management:
- Spatie Laravel Permission (Spatie Roles)

TECH STACK SUMMARY:
- Laravel 12 handles the main application structure, routing, models, controllers, authentication, and backend logic.
- Livewire 4 is used for dynamic and reactive interfaces without writing a separate frontend framework.
- MySQL is used to store users, OJT assignments, attendance, duty hours, reports, evaluations, tasks, and announcements.
- Flux Components are used to build the UI such as sidebars, forms, cards, modals, and tables.
- Spatie Roles is used to manage access control for Admin, OJT Coordinator, Professor, Company Supervisor, and Student.


==================================================
SYSTEM RULES
==================================================

- A student can only have ONE OJT assignment at a time.
- The OJT Coordinator decides the student's OJT type:

    a. Internal OJT → assigned to a Professor
    b. External OJT → assigned to a Company Supervisor

IMPORTANT:

- Company Supervisor already represents the company.
- There is NO separate "Company" entity.
- The Company Supervisor account contains company details.

Supervisor Types:
- Professor → handles INTERNAL OJT
- Company Supervisor → handles EXTERNAL OJT

Both have the SAME FEATURES.

PRODUCTIVITY RULE:

- Productivity / Kanban is only for:
  - Professor
  - Company Supervisor
  - Student

- Productivity / Kanban is NOT for:
  - Admin
  - OJT Coordinator

==================================================
THESIS DESCRIPTION (FINAL)
==================================================

DutyTrack is a web-based system designed to monitor OJT attendance and duty hours using a role-based structure and a modern Laravel-based technology stack.

The system is built using Laravel 12, Livewire 4, MySQL, Flux Components, and Spatie Roles. Laravel 12 serves as the core application framework, Livewire 4 powers reactive interfaces, MySQL stores system data, Flux Components provide the user interface components, and Spatie Roles manages role-based permissions and access control.

Students are assigned by the OJT Coordinator to either an internal OJT under a Professor or an external OJT under a Company Supervisor. The Company Supervisor represents the partner company within the system.

Both Professor and Company Supervisor share the same supervisory functionalities, including task management through a kanban board, productivity monitoring, and student evaluation. The Student also has access to the productivity board to update assigned tasks and track progress. Admin and OJT Coordinator focus on management, assignment, monitoring, reporting, and system control rather than direct productivity handling.
